# Changelog

## 0.1.2 — 2026-11-12

- Added a new extension icon and a coordinated Marketplace banner.
- Reworked the listing with a visual introduction, cropper preview, setup steps, and command reference.
- Clarified local photo storage, reset behavior, the CSS dependency, and update compatibility.

- Fixed saved avatars not applying when VS Code uses a `vscode-userdata:` storage URI.

## 0.1.0 — 2026-11-10

- Initial local release with image selection, drag/zoom cropping, keyboard positioning, and icon-size preview.
- Added save, reapply, and reset commands, plus migration from the original local cropper.
